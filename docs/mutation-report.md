# Мутаційне тестування

**Відтворення:** `make mutation` (обгортка `npm run test:mutation`).
**Інструмент:** Stryker 10.1.1 + vitest-runner, конфіг — [`stryker.config.json`](../stryker.config.json).
**Обсяг:** мутується `src/services/grades.service.ts`, мутантів вбивають лише unit-тести (`tests/unit`), без БД і Docker.

## Результат

Mutation score **86.57%** (поріг зі spec — 80%, нижче команда падає): 67 мутантів, 58 вбито, 9 вижило.

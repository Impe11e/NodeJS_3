# Електронний журнал

«Електронний журнал» — навчальний бекенд-застосунок для обліку оцінок студентів. Система дозволяє викладачам виставляти оцінки за заняття з власних предметів, а студентам — переглядати свої оцінки та середній бал.

---

## Стек технологій

- Node.js, Fastify
- PostgreSQL
- Jest — тести
- ESLint — лінтер
- Prettier — форматер
- Husky + lint-staged — git hooks

---

## Архітектура та принципи

Застосунок спроєктовано за принципом **модульного моноліту**:

* **Тришарова структура:** Кожен модуль має чіткий поділ на шари: `routes` $\rightarrow$ `service` $\rightarrow$ `repository`.
* **Ізоляція даних:** Модуль володіє тільки власними таблицями в БД. Прямі запити до чужих таблиць заборонені — взаємодія між модулями відбувається виключно через сервісний шар (`service`).
